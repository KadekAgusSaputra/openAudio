Token Hugging Face

Token bersifat opsional. Masukkan token Hugging Face (hf_...) untuk melanjutkan saat kuota gratis habis. Token disimpan di sessionStorage browser ini saja.

Cara mendapatkan token di Hugging Face (Step-by-Step)

  1. Buka menu profil di halaman awal: Klik menu/ikon profil di pojok kanan atas Hugging Face, lalu pilih Profile atau langsung masuk ke Settings / Access Tokens.
  2. Masuk ke Access Tokens & buat token: Di menu kiri pilih Access Tokens, lalu klik + Create new token di kanan atas.
  3. Beri nama, pilih izin, lalu salin token: Isi nama token (misalnya openaudio-user), pilih izin secukupnya (Read), lalu salin token yang diawali hf_....
  4. Tempel di web OpenAudio: Masukkan token ke kolom di atas atau di kolom token header, lalu klik Simpan & Verifikasi Token.
